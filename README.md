# Stocks Demo

此專案為證券相關 Android 實作考題，主要展示股票資料取得、資料處理與介面呈現。

## 架構

MVVM + Clean Architecture
  
## 技術

- Kotlin
- Jetpack Compose
- Hilt
- Retrofit
- Kotlin Coroutines / Flow
- DataStore
- Material 3

## 功能

- 股票資料查詢與顯示
- 股票漲跌資訊呈現
- 股票資料排序
- 日間/夜間主題切換

## 專案目的

本專案為證券實作考題使用，著重於 Android App 架構設計、程式碼可維護性、UI 實作。
